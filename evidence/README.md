# Evidencias a guardar
Guarda capturas o logs reales de:
1. `python --version`
2. `arduino-cli version`
3. `arduino-cli core list`
4. `arduino-cli board listall esp32`
5. Compilación de un sketch mínimo con el FQBN seleccionado.
6. Archivos generados y ubicación del `.bin`.
7. Error de compilación controlado, si se prueba.
8. Carga física, solo si realmente se ejecuta con una placa.

No usar capturas simuladas ni inventar resultados.
